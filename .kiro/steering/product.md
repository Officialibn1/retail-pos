# Product Overview

This is a **Retail Point of Sale (POS) System** designed for retail stores. The application provides comprehensive store management capabilities including:

- Sales processing and checkout
- Inventory management with stock tracking
- User management with role-based access control
- Analytics and reporting dashboards
- Receipt generation and printing
- Customer management
- Activity logging

## User Roles

The system supports four user roles with different permission levels:

- **SUPERADMIN**: Full system access, can manage users
- **ADMIN**: Administrative access
- **MANAGER**: Can view all data, manage inventory, view activity logs
- **CASHIER**: Basic sales and checkout operations

## Currency

The system uses Nigerian Naira (₦) as the primary currency.
